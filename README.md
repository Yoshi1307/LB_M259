# LB_M259
Mein Datensatz besteht aus Spielstatistiken vergangener Premier League Spiele von der Saison 22-23 bis hin zu 00-01
In meinem Datensatz gibt es die Felder:

| Spaltenname                     | Bedeutung                                                                             |
| ------------------------------- | ------------------------------------------------------------------------------------- |
| Season                          | In welcher Season das Spiel war                                                       |
| League                          | In welcher Liga das Spiel war                                                         |
| HomeTeam                        | Heimteam                                                                              |
| AwayTeam                        | Auswärtsteam                                                                          |
| FTHG (Full Time Home Goals)     | Anzahl Tore des Heimteams am Ende des Spiels                                          |
| FTAG (Full Time Away Goals)     | Anzahl Tore des Auswärtsteams am Ende des Spiels                                      |
| FTR (Full Time Result)          | Wer das Spiel gewonnen hat                                                            |
| HTHG (Half Time Home Goals)     | Tore des Heimteams zur Halbzeit                                                       |
| HTAG (Half Time Away Goals)     | Tore des Auswärtsteams zur Halbzeit                                                   |
| HTR (Half Time Result)          | Resultat zur Halbzeit (H = Heimteam führt, D = Unentschieden, A = Auswärtsteam führt) |
| HS (Home Team Shots)            | Schüsse des Heimteams                                                                 |
| AS (Away Team Shots)            | Schüsse des Auswärtsteams                                                             |
| HST (Home Team Shots on Target) | Schüsse aufs Tor vom Heimteam                                                         |
| AST (Away Team Shots on Target) | Schüsse aufs Tor vom Auswärtsteam                                                     |
| HC (Home Team Corners)          | Eckbälle des Heimteams                                                                |
| AC (Away Team Corners)          | Eckbälle des Auswärtsteams                                                            |
| HF (Home Team Fouls Committed)  | Fouls des Heimteams                                                                   |
| AF (Away Team Fouls Committed)  | Fouls des Auswärtsteams                                                               |
| HY (Home Team Yellow Cards)     | Gelbe Karten des Heimteams                                                            |
| AY (Away Team Yellow Cards)     | Gelbe Karten des Auswärtsteams                                                        |
| HR (Home Team Red Cards)        | Rote Karten des Heimteams                                                             |
| AR (Away Team Red Cards)        | Rote Karten des Auswärtsteams                                                         |


## Lizenz:
Der Datensatz enthält nur Informationen zu Fussballspielen der Premier League, z.B die Anzahl Schüsse und die Resultate. Es sind keine persönlichen Daten von einzelnen Personen enthalten, wie Namen, Adressen oder Kontaktdaten. Deshalb werden keine Datenschutzrichtlinien verletzt. Die Daten stammen aus öffentlich verfügbaren Sportstatistiken, die bereits gesammelt und veröffentlicht wurden.(Laut ersteller von hier: https://www.football-data.co.uk/data.php ) In meinem Projekt habe ich nur diese vorhandenen Spieldaten verwendet und keine zusätzlichen personenbezogenen Daten hinzugefügt. Dadurch bleibt der Datenschutz gewährleistet.
